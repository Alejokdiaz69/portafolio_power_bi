# Portafolio de Análisis de Datos e Inteligencia de Negocios

Repositorio oficial de mi portafolio profesional como Data Analyst. Este espacio documenta la arquitectura técnica, el modelado de datos y el diseño visual detrás de mis soluciones analíticas y procesos de automatización ETL (Extract, Transform, Load). 

Todos los proyectos presentados utilizan conjuntos de datos ficticios o casos de estudio reales estrictamente anonimizados para proteger la confidencialidad corporativa.

## Perfil Técnico

Mi enfoque se centra en transformar datos crudos en herramientas tácticas para la toma de decisiones gerenciales y operativas. Mis principales áreas de especialidad incluyen:

*   **Visualización y Modelado:** Desarrollo de dashboards interactivos en Power BI, diseño de esquemas relacionales (Star Schema) y formulación de medidas avanzadas con DAX.
*   **Gestión de Bases de Datos:** Extracción y manipulación de datos mediante consultas estructuradas en SQL Server.
*   **Automatización ETL:** Creación de scripts en Python para la limpieza, transformación de datos y configuración de flujos de trabajo automatizados para la actualización recurrente de reportes.

## Índice de Proyectos Destacados

A continuación, presento los módulos documentados en este repositorio. Cada directorio contiene su respectiva explicación técnica, arquitectura de datos y capturas del modelo funcional.

### 1. Gestión de Ventas y Productividad Operativa
*Ubicación en el repositorio: `Informe BI/Proyecto Reporte Gerencial/`*

Modelo enfocado en el seguimiento integral de una operación comercial. Evalúa la productividad, el cumplimiento de metas financieras y las métricas de adherencia mediante el cálculo de indicadores como el SPH (Sales Per Hour) y la clasificación dinámica por cuartiles de rendimiento.

### 2. Seguimiento Backoffice: Conversión y Logística
*Ubicación en el repositorio: `Informe BI/Proyecto Seguimiento ventas/`*

Herramienta analítica de visión completa (end-to-end) que audita el embudo de ventas desde la captación comercial hasta la entrega logística. Incluye análisis cualitativo (motivos de rechazo), impacto del backlog y evaluación del cumplimiento de promesas de entrega (SLA) de proveedores de transporte.

### 3. Monitoreo de Tráfico Inbound (Contact Center)
*Ubicación en el repositorio: `Informe BI/Proyecto Trafico Inbound/`*

Dashboard orientado a Workforce Management (WFM) para controlar el volumen de llamadas entrantes frente a proyecciones (Forecast). Mide métricas críticas como el Nivel de Servicio, Tasa de Abandono y Tiempos Medios de Operación (TMO) en ventanas temporales intradía.

### 4. Estrategia y Comportamiento de Bases (Outbound)
*Ubicación en el repositorio: `Informe BI/Proyecto Status Bases/`*

Sistema diseñado para auditar el desempeño de campañas de salida, evaluando el consumo y calidad de las bases de datos (leads). Mide la contactabilidad, la intensidad de marcación (vueltas por registro) y la efectividad bruta/neta cruzada por canales estratégicos.
